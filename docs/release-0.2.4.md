# 元枢客户端 0.2.4 · 2026-09-12

## 安装包

- Windows x64：`D:/pi-workspace/交付/元枢桌面客户端/元枢_0.2.4_x64-setup.exe`
- Android arm64：`D:/pi-workspace/交付/元枢安卓App/元枢-Android-arm64-0.2.4.apk`

Android 包名为 `com.yuanshu.app`，versionCode 为 `2004`；使用 release 编译，沿用此前 0.2.1/0.2.2 的本机签名，可以覆盖同签名的旧版本。安装时保留旧应用数据，不需要先卸载。

## 本次更新

- 资产库点击 PPTX 可查看按页提取的文字内容；这是内容预览，不是原始幻灯片视觉渲染。
- 手机关闭资产预览时同步收起详情遮罩，避免阻挡底部导航。
- 手机任务历史按日期分组，结果正文取消重复图标列、扩大可读宽度。
- 下载中心支持记录、重试与清理；手机操作按钮扩大到 44×44。
- 桌面客户端可打开系统下载目录；已确认桌面 WebView2 能将下载文件实际写到系统 Downloads。
- Android 通过系统保存窗口选择位置，确认保存后记录“已保存”，并支持打开已保存文件。取消、失败和传输途中离开页面不会记为保存成功。

## 验证边界

前端类型检查、构建、自动化测试以及 360/390px 浏览器模拟验收已完成；Android 下载数据的 JVM 单元测试与 release 构建已通过，签名和版本已核对。Android 没有连接手机实测，系统保存窗口、覆盖安装与外部应用打开文件仍需按 `docs/android-real-device-acceptance.md` 验收。
