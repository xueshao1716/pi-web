# 兰州羊皮筏子 · 文化科普站

黄河上游传统水上交通工具「羊皮筏子」的文化科普静态网站。

## 页面

| 文件 | 内容 |
|------|------|
| `index.html` | 首页：书法标题 + 水墨 Hero + 三板块入口 |
| `history.html` | 溯源：起源「浑脱」+ 唐代至当代时间线 |
| `craft.html` | 技艺：选羊→扎筏七道工序 + 绑扎结构剖面 |
| `culture.html` | 传承：价值、诗词民谚、现状保护 |

## 运行

纯静态站点，无框架、无外部依赖。直接双击 HTML 打开，或：

```bash
cd yangpifazi && python -m http.server 8000
```

## 设计系统

- 风格：传统东方水墨风（宣纸噪点底、墨色、朱砂印章、赭石/土黄点缀）
- 字体：系统楷体/宋体栈（`KaiTi / STKaiti / SimSun / Songti SC`），无网络字体依赖
- 插画：全部为内联 SVG 手绘水墨风格（筏子、筏工、皮囊剖面、印章等），零版权问题
- 交互：滚动显现动画（IntersectionObserver）、导航悬浮动效，均尊重 `prefers-reduced-motion`

## 内容说明

- 文案基于公开史料整理；史实不确定处均标注「一说 / 民间说法 / 民间俗称」，未作硬性断言
- 非遗名录年份等官方认定信息未写具体数字，避免不准确表述

## 维护

- 改配色：编辑 `assets/style.css` 顶部 `:root` 变量
- 改插画：各页面内联 `<svg>` 直接编辑
