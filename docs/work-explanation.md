# 工作说明怎么读

在聊天底部展开「过程与依据」，可看到这一轮的目标、执行引擎与模型、已有依据、记忆写入、工具、子智能体、产物及检查。工作台、引擎控制台的运行诊断、改动验收中的近期工作说明使用相同记录。

| 提示 | 具体含义 |
| --- | --- |
| 本轮已结束 | 本轮回复或执行结束，不等于要求已经全部达成。 |
| 尚无检查记录 | 没有收到可核对的检查结果，不应据此认定产物可用。 |
| 仅有模型自报 | 模型说检查过，但没有对应的运行时检查记录。 |
| 已记录检查通过 | 已执行并记录的检查通过，检查范围之外仍需核对。 |
| 有检查未通过 | 有运行时检查失败，需要处理具体问题。 |
| 未收到结束记录 | 只看到了开始记录，不能确定工具或子任务是否成功。 |
| 记忆写入 | 本轮保存记忆的记录，不表示检索命中。 |
| 产物记录 | 记录了位置，不自动证明文件可打开、视频可播放或下载已完成。 |
| 子智能体自评把握 | 子智能体对自身结论的判断，不能代替验证。 |

当前情绪属于整个会话的当前状态，不是过去某轮的情绪快照。缺失的旧记录会明确标注，不会补造模型的思考过程。系统提示和路由依据来自已记录的事件，不会额外请求模型编写解释。

当前版本整理已有工作记录，不会自动验收所有产物。聊天执行链路尚未接入独立检查结果的采集，所以即使工具运行成功，也会显示“尚无检查记录”；请实际预览文件、播放视频并核对内容。子智能体的任务和结论以脱敏、限长的摘要显示，系统提示词、模型历史和隐藏推理不会展示。

运行证据只适用于对应的那一次任务，不能用另一任务的检查结果证明当前仓库已经验收。人工验收仍由使用者根据目标和产物决定。

接口继续使用 `/api/run/overview` 和 `/api/runs/:id`。概览可用 `?session=<会话 ID>` 限定范围，说明字段为 `explanation`，版本为 1。升级前端后刷新页面即可使用；没有运行台账的旧会话仍以原对话内容为准。

如果系统更新或网络中断时提示“页面未加载完整”，点击“重新加载页面”可重新获取页面资源。普通显示异常仍提供“重试”，技术报错收在“错误详情”内。
