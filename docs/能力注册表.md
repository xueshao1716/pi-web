# 能力注册表（pi-web 好功能登记）

> 目的：防止升级/重构误伤好功能。所有登记能力 = 资产，升级动它必须有契约测试证明没坏。
> 维护：新增/修改能力时更新此表 + 关联测试。删除能力 = 从这里删除并说明原因。

## 使用方式

1. **升级/重构前**：`git diff` 对照本表，确认动到的模块
2. **动到登记能力**：跑 `npm test` + `tests/unit/capabilities.test.mjs`（契约测试）
3. **人工抽验**：登记能力每项对话试一次（身份问答/复读/工具任务/图片）

## 变更纪律

- **删除/弱化任何登记能力** → 必须先过契约测试 + 在文档记录原因
- **新模块命名** → 先 `ls engine/` 查重（model-probe 撞名教训）
- **模板拼接** → 变量必须 fallback（`x || "默认"`），防 undefined 泄漏
