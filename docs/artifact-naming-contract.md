# 生成物命名契约

所有由元枢保存的图片、视频和音频，都通过 `saveArtifact()` 统一命名并落在 `生成物/<类型>/<本地日期>/` 下。

文件名格式：

```text
<主题 slug>_<类型>_<YYYYMMDD-HHmmss-mmm>-<随机短 ID>.<扩展名>
```

例如：

```text
定西洋芋宣传图_图片_20260913-181245-037-7c21a9f0.png
焦点访谈模型对谈_视频_20260913-181301-442-0b4d8e12.mp4
```

约束：

- 主题只取提示词中的可读摘要，清理 Windows 非法字符、控制字符和路径分隔符，并限制长度。
- 类型由 `artifact.type` 决定，扩展名不能由模型或远程 URL 覆盖。
- 时间使用本机日历时间，精确到毫秒；随机短 ID 解决并发和跨任务重名。
- 如果历史文件已经占用同名路径，系统通过原子占位自动追加 `-2`、`-3`，绝不覆盖已有文件。
- 旁路提示词文件与最终媒体文件同名，仅将扩展名替换为 `.json`；保存失败会清理占位文件。
- 资产列表和交付记录应以完整相对路径识别产物，不能只按显示名称合并。
