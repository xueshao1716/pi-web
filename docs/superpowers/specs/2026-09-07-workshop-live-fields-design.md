# 工坊镜头卡格子要活（2026-09-07）

## 问题

点运镜骨架只把芯片上的字拷进光影/运镜/风格。仙侠主体配急推骨架会变成「青衣修士 + 硬顶光切开半张脸」。绘图的光影/风格还被下拉白名单卡住，智能填充写不进去。

## 做法

格子按「当前人、地点 × 这套拍法」现写。

- 主体/动作/场景：骨架不覆盖；示例成稿可以覆盖。
- 光影：从地点推断光源（山道→冷月光，地铁→冷白顶灯），再接上骨架的光形（切开半张脸、冷暖差…）。地点读不出来才用骨架原句。
- 运镜/画幅/约束：仍用骨架，但要能带上当前主体。
- 风格：骨架风格 + 地点能认的一句（古装山道、车厢顶灯）。
- 改地点且光影仍是上次自动写的：再合成一次。人手改过的光影不动。
- 智能填充：八个格子都写；绘图光影/风格不再白名单过滤。
- 绘图：光影/氛围/风格改成可打字；构图骨架同样按背景/服装现写光。

## 不做

不把骨架改回整卡故事。不加新的视频类型芯片（先让现有组合活起来）。
